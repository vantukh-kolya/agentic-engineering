## Inlined context

> Ухвалений обсяг — спільний перелік сесій усіх проєктів одного джерела, побудований лише з метаданих файлів. Сортування за свіжістю, обмеження кількості та явні порожній і частково доступний стани допомагають знайти сесію й розуміти повноту результату.

— `spec.md §1, committed approach, verbatim` · [повний текст](../spec.md)

> - Вміст JSONL не читається взагалі, навіть дозволені ADR-0001 службові поля. Можна читати імена, розмір і mtime. Виняток підготовки синтетичних фікстур у `scripts/pin-fixture-mtimes.mjs` не є runtime індексу.

— `spec.md §6, приватність читання, verbatim` · [повний текст](../spec.md)

> - Обсяг: одне джерело Claude Code. `CLAUDE_HOME` або типовий шлях визначає джерело; фіча не додає вибору довільного шляху з браузера.

— `spec.md §6, ізоляція джерела, verbatim` · [повний текст](../spec.md)

> Кандидати — лише звичайні `.jsonl` безпосередньо у звичайних теках проєктів. Тип перевіряється без переходу за символічними посиланнями; вкладені елементи не обходяться, навмисно виключені типи не збільшують лічильники помилок. Налаштоване джерело залишається єдиним навіть за порожнечі чи помилок. Усі очікувані файлові збої перетворюються на модель результату на відповідному рівні, без сирих винятків у HTML чи логах. Відсутність кореня треба відрізняти від відмови доступу, не підміняючи будь-який збій порожнім масивом.

— `sad.md §6, Filesystem boundary, verbatim` · [повний текст](../sad.md)

> - **When:** індекс обробляє синтетичне дерево з довільним або нечитабельним вмістом основних файлів, окремо з явно налаштованою іншою домашньою текою.
> - **Then:** «0 відкриттів вмісту журналів у runtime індексу»; «0 операцій запису з runtime індексу в домашню теку джерела»; «0 звернень до особистої домашньої теки агента з тестів та demo» (spec §6, рядки Приватність читання / Недоторканність джерела / Ізоляція перевірок).
> - **How verify:** контроль синхронних файлових викликів на ізольованому синтетичному джерелі, контроль `CLAUDE_HOME` до імпорту сервера, порівняння складу, вмісту та mtime дерева до й після запиту. Тестовий код може читати синтетичний вміст для порівняння; runtime індексу — ні. Зміна вмісту зі збереженням метаданих не змінює рядків індексу. atime не є гарантією.

— `sad.md §10, QG-1, verbatim` · [повний текст](../sad.md)

> | Безпека HTML | `esc()` для всіх значень із джерела, зокрема повного ID, початкового імені теки, похідного підпису й шляху джерела. Для динамічних атрибутів використовувати подвійні лапки й екранування. Похідний підпис не є файловим шляхом для обходу | AGENTS, rules/views, spec AC-03, AC-14 |

— `sad.md §8, Безпека HTML, verbatim` · [повний текст](../sad.md)

> - Використовуються наявні серверне складання HTML, стилі, тема й тестовий рушій; без нових залежностей, фронтенд-збірки чи сховища. `npm start` агент не запускає; для огляду — лише demo.

— `spec.md §6, обмеження стеку, verbatim` · [повний текст](../spec.md)

> **Chosen:** варіант 1, підтверджений власником. `listSessions()` адаптера повертає всі зібрані метадані та діагностику повноти. Маршрут перевіряє `limit` до запуску обходу, сортує доступні рядки за mtime, початковим ім'ям теки проєкту та ID, після чого застосовує ліміт. HTML-шар отримує готову модель відображення й не звертається до диска.
>
> Отримання адаптера відбувається через наявний `getSource('claude')`; реєстрація й імпорт адаптера зберігаються. Друге джерело й новий універсальний сервісний шар не додаються.

— `adr/0002-return-complete-metadata-before-presentation-selection.md §Decision outcome, ADR-0002, verbatim` · [повний текст](../adr/0002-return-complete-metadata-before-presentation-selection.md)

> | `views/sessions.js` | HTML переліку, підсумків, порожнього й помилкових станів із готової моделі | Не імпортує адаптер чи `node:fs`; усі значення даних проходять `esc()` |

— `sad.md §5, межа модуля, verbatim` · [повний текст](../sad.md)

> | Власні рядки проєктів і шлях джерела можуть створити розмітку або розкрити приватні назви | High | `esc()` на всіх динамічних значеннях, локальний слухач, незмінна CSP, відсутність нового логування. Security review до приймання, як вимагає spec §6.1 | maintainer |

## Acceptance criteria

### AC-02 (US-01, US-05) — domain invariant

> **Given** поруч з основними файлами сесій є вкладені транскрипти субагентів, результати інструментів і сторонні файли
> **When** розробник переглядає індекс сесій
> **Then** перелік містить тільки сесії за визначенням словника; вкладені й сторонні файли не створюють рядків і не збільшують кількість сесій.

— `spec.md §5, AC-02, verbatim` · [повний текст](../spec.md)

### AC-11 (US-05) — cross-context

> **Given** для джерела явно налаштована інша домашня тека, ніж типова
> **When** розробник відкриває індекс сесій
> **Then** бачить лише сесії з налаштованої теки та позначення поточного джерела; сесії з типової теки не домішуються й не підставляються, навіть коли налаштована тека порожня або недоступна.

— `spec.md §5, AC-11, verbatim` · [повний текст](../spec.md)

### AC-12 (US-05) — domain invariant

> **Given** серед елементів джерела є символічні посилання на проєкти, файли або вкладені теки
> **When** розробник відкриває індекс сесій
> **Then** ці посилання не розгортаються і не додають сесій; перелік не виходить за межі налаштованого джерела через його дочірні посилання й не вважає навмисно виключені елементи помилками читання.

— `spec.md §5, AC-12, verbatim` · [повний текст](../spec.md)

### AC-13 (US-05) — domain invariant

> **Given** основні файли сесій мають доступні метадані, але містять довільний, пошкоджений або недоступний для читання зміст
> **When** розробник відкриває індекс сесій
> **Then** бачить ті самі метадані без вимоги прочитати зміст; жоден фрагмент розмови не показаний, файли сесій не змінені.

— `spec.md §5, AC-13, verbatim` · [повний текст](../spec.md)

### AC-14 (US-02, US-06) — domain invariant

> **Given** ім'я проєкту, ідентифікатор чи шлях джерела містить спеціальні символи розмітки
> **When** розробник відкриває перелік
> **Then** значення показані як звичайний текст; вони не створюють елементи сторінки й не виконують команди в браузері.

— `spec.md §5, AC-14, verbatim` · [повний текст](../spec.md)

### AC-15 (US-06) — happy

> **Given** розробник користується наявною оболонкою дашборду
> **When** відкриває перелік і перемикає тему
> **Then** бачить заголовок agent-ops, наявну навігацію й робочий перемикач світлої та темної тем; обрана тема зберігається за наявною поведінкою, а перевірка стану застосунку надалі підтверджує його роботу й поточне джерело.

— `spec.md §5, AC-15, verbatim` · [повний текст](../spec.md)

## Edge cases

| Case | Behaviour |
|---|---|
| Вміст нечитабельний, метадані доступні | Сторінка працює без спроби відкривати журнал. |
| Markup у home або полях рядка | Тільки екранований текст у body й атрибутах. |
| Спроба runtime-запису без зміни файла | Тест фіксує порушення, навіть якщо snapshot не змінився. |
| Змінений синтетичний вміст з тим самим size/mtime | Ті самі метадані в індексі. |

— `spec.md §5, AC-02, AC-11, AC-12, AC-13, AC-14, AC-15, abridged` · [повний текст](../spec.md); `sad.md §6, Failure handling / Filesystem boundary, abridged` · [повний текст](../sad.md).
