### Findings

Обидві знахідки — **підтверджені факти**, відкриті для рішення maintainer. Непідтверджених підозр як дефектів не подано.

**F1 — High; stage-1 і stage-2: заміна теки проєкту symlink порушує ізоляцію джерела.** Місце: `lib/claude/sessions.js:19`–23, :32. Порушено AC-12 (`spec.md:149`, :186), filesystem boundary (`sad.md:164`, :184), ізоляцію US-05. `isDirectory()` береться зі старого Dirent кореневого readdir; наступний `readdirSync(projectDirectory)` розгортає вже підмінене посилання. `lstat` файла не захищає від symlink у батьківському компоненті.

Вплив: ID і метадані зовнішньої сесії показуються під ключем внутрішнього проєкту як `complete`, без skips. Реальний symlink у синтетичному R1 нижче дав `id: outside`, `state: complete`, `skippedProjects: 0`, `skippedFiles: 0`. Це не припущення про можливу гонку: момент заміни детермінований на реальній файловій системі. Неатомарність snapshot зі spec:190 не скасовує окремої заборони переходу за дочірніми посиланнями. Тестові звичайні symlink Dirent та file→link цього не ловлять.

Напрям виправлення для рішення власника: забезпечити no-follow/ідентичність теки на переході в project і під час доступу до її файлів; виключити замінений елемент і додати детермінований project→link тест. Один додатковий попередній lstat не усуває TOCTOU повністю. У цьому review виправлення не виконувалося.

**F2 — Medium; stage-1 і stage-2: масивоподібний limit мовчки запускає типовий перелік.** Місце: `server.js:19`–20; `test/session-limit.test.js:23`–38. ### Reproduction R1 — actual directory symlink replacement

Рецензент виконав JavaScript нижче через `node --input-type=module -e '<JavaScript>'`, exit0. Тут наведено еквівалентну самодостатню форму для повторення з cwd репозиторію. Створює лише власне tmp дерево та справжній directory symlink; обгортка readdirSync задає момент гонки після справжнього root read. Готовий результат reader не підставляється. У finally підміна відновлюється, власне дерево видаляється. Особистих шляхів немає.

```sh
node --input-type=module <<'JS'
import fs from 'node:fs';
import { join } from 'node:path';
import { tmpdir } from 'node:os';
import { syncBuiltinESMExports } from 'node:module';
import { listSessions } from './lib/claude/sessions.js';
const base = fs.mkdtempSync(join(tmpdir(), 'review-symlink-'));
const root = join(base, 'home', 'projects');
const project = join(root, '-project');
const outside = join(base, 'outside');
fs.mkdirSync(project, { recursive: true });
fs.mkdirSync(outside);
fs.writeFileSync(join(project, 'inside.jsonl'), 'synthetic');
fs.writeFileSync(join(outside, 'outside.jsonl'), 'synthetic');
const original = fs.readdirSync;
fs.readdirSync = (path, ...args) => {
  const entries = original(path, ...args);
  if (path === root) {
    fs.rmSync(project, { recursive: true });
    fs.symlinkSync(outside, project, 'dir');
  }
  return entries;
};
syncBuiltinESMExports();
try {
  console.log(JSON.stringify(listSessions(root)));
} finally {
  fs.readdirSync = original;
  syncBuiltinESMExports();
  fs.rmSync(base, { recursive: true, force: true });
}
JS
```
